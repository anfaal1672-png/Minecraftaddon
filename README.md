# いろんなTNT追加アドオン (Many TNT Addon)

Minecraft 統合版 (Bedrock) に **77 種類のユニークなTNT**、リモート起爆装置、TNT図鑑を追加するアドオンです。

- 核爆弾・ブラックホール・時間停止・地雷・時限爆弾・橋を架けるTNT など
- 着火すると本物のTNTと同じように導火線が燃え、飛んだり落ちたりします
- 日本語・英語に対応しています (ゲームの言語設定に合わせて表示)
- 地形を壊さない「安全モード」や威力の倍率などを、ゲーム内の設定メニューで変えられます

TNTの一覧・効果・レシピは **[docs/TNT_LIST.md](docs/TNT_LIST.md)** を見てください。

## 導入方法

1. リポジトリ直下の [`many_tnt_addon.mcaddon`](many_tnt_addon.mcaddon) をダウンロードします。
2. ファイルを開く (ダブルクリック / 共有から Minecraft を選ぶ) と、ビヘイビアパックとリソースパックが読み込まれます。
3. ワールドの設定で **ビヘイビアパック「いろんなTNT追加アドオン」** を有効にします (リソースパックは自動で付いてきます)。

**必要なバージョン:** Minecraft 統合版 **1.26.20 以上**。実験的な機能のトグルは不要です。

v30 以前から更新する場合も、同じワールドでそのまま使えます (パックの UUID とブロックの ID は変えていません)。

## 遊び方

| 操作 | 内容 |
|---|---|
| 火打石で右クリック | 着火 (耐久値が1減ります) |
| 炎・溶岩の隣に置く / レッドストーン信号 / 燃えた矢 / 近くの爆発 | 着火 (通常のTNTと同じ) |
| 起爆装置でTNTを右クリック (しゃがみながら) | そのTNTを起爆装置に登録 / 解除 (最大16個) |
| 起爆装置を右クリック | 登録したTNTを一斉起爆 (64ブロック以内)。登録がなければ視線の先のTNTを起爆 |
| 起爆装置を右クリック (しゃがみながら、空中) | 登録の一覧・全解除 |
| TNT図鑑を使う | カテゴリ別の一覧・説明・レシピ・自分の使用回数を表示。オペレーターは設定も開けます |

### コマンド

| コマンド | 内容 |
|---|---|
| `/scriptevent manytnt:help` | TNT一覧と使い方 |
| `/scriptevent manytnt:stats` | 累計爆発数・使った種類・よく使う上位5種・自分の記録 |
| `/scriptevent manytnt:mute` | 爆発時のチャット演出のON/OFF |
| `/scriptevent manytnt:settings` | 設定メニュー (オペレーターのみ) |
| `/scriptevent manytnt:guide` | TNT図鑑を開く |

### 設定 (オペレーターのみ)

| 項目 | 初期値 | 内容 |
|---|---|---|
| 地形破壊 | ON | OFF にすると「安全モード」。爆発でブロックが壊れず、火・溶岩も出ません。効果 (エフェクト・召喚・ブロックの設置など) は動きます |
| 威力の倍率 | ×1 | ×0.25〜×2。核系のクレーターの大きさにも効きます (爆発の威力は最大100) |
| 核系TNTの着火を許可 | ON | OFF にすると核・超核・水素爆弾・ツァーリボンバ・反物質・終焉TNTが着火しません |
| 連鎖着火の上限 | 60/秒 | 大量のTNTを並べたときの負荷対策。超えた分は順番待ちになり、消えません |
| チャット演出 | ON | 爆発時のメッセージ |
| ガチャTNTの排出 | 通常 | 「核系なし」にするとガチャから核系が出なくなります (通常でも合計1%未満) |
| 燃えているTNTの名前表示 | 日本語 | 燃えているTNTの頭上に出る名前の言語 |

## 開発

TNTの定義は `tools/defs/tnt.json` にまとまっていて、ブロック・レシピ・ルートテーブル・言語ファイル・テクスチャの定義などは
すべてそこから生成します。スクリプトは `packs/BP/scripts/` にあります。

```bash
npm install          # 型定義と @minecraft/vanilla-data (検証用) を入れる
npm run generate     # tools/defs → packs/ の定義ファイルを生成
npm run validate     # 整合性チェック (JSON・言語キー・テクスチャ・レシピ材料・バージョン・構文など)
npm test             # @minecraft/server のモックを使ったユニットテスト
npm run build        # 生成 → 検証 → many_tnt_addon.mcaddon を作成
```

| フォルダ | 内容 |
|---|---|
| `tools/defs/` | 正本: TNT定義 (`tnt.json`)、パック情報とアイテム (`meta.json`)、メッセージ (`messages.json`) |
| `tools/` | 生成・検証・ビルドのスクリプト |
| `packs/BP/scripts/core/` | 着火・爆発・スケジューラー (1tick の処理量の上限)・安全処理 |
| `packs/BP/scripts/effects/` | 各TNTの効果 (核・属性・物理・生き物・地形・お楽しみ) |
| `packs/BP/scripts/systems/` | 設定・統計・多言語・コマンド・起爆装置・地雷 |
| `packs/BP/scripts/ui/` | TNT図鑑・設定メニュー |
| `test/` | ユニットテストとモック |

新しいTNTを追加するときは `tools/defs/tnt.json` に1件足し (テクスチャは `texture` に色を書けば自動生成)、
効果が必要なら `effects/` に関数を書いて `effects/index.js` に登録し、`npm run build` を実行します。

変更履歴は [CHANGELOG.md](CHANGELOG.md)、ゲーム内での確認手順は [TEST_PLAN.md](TEST_PLAN.md) にあります。
